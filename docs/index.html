VRTwKeyboard 安裝器

把臺灣注音輸入法裝進你的 Meta Quest。不用安裝任何軟體，這個網頁就是安裝器。

這個瀏覽器不支援

安裝需要 WebUSB，只有 Chromium 系的瀏覽器有：Chrome、Edge、Opera。 Safari 與 Firefox 都不支援。

手機也可以——用安卓手機的 Chrome 加一條 OTG 線同樣能裝。iPhone 不行。

另外，不能用頭盔自己的瀏覽器：裝置沒辦法用 USB 連自己。

開始之前

  1. 手機的 Meta Horizon App →「裝置」→ 選你的頭盔 →「開發者模式」打開
  2. 用 USB 線把頭盔接到這台電腦（或安卓手機）
  3. 戴上頭盔，會跳出「允許 USB 偵錯」，選允許並勾選「一律允許」

安裝

準備好之後按下面的按鈕，瀏覽器會請你選擇裝置。

裝好之後

  1. 在頭盔的應用程式清單找到 注音輸入法，打開它
  2. 按「開啟鍵盤設定」，把注音輸入法打開
  3. 要用語音輸入的話，按「允許使用麥克風」，再按「下載語音模型」（226 MB）

語音模型和之後的版本更新都可以在頭盔裡直接下載，不用再接電腦。
